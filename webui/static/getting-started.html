How HEATR heats a part, and how to drive it

HEATR couples an electro-quasi-static field solve, RF power deposition, and transient thermal + melt + densification physics. The walkthrough below shows the full pipeline, then how to launch a run and read your results.

The field guide — physics pipeline, Operation page, and Results browser. Loops automatically; drag the scrubber to review any moment.
01

Configure a run

On the Operation page pick a mode and shape, set the exposure, then Launch Run.

02

Watch it solve

The active-job panel tracks progress; live figures show the field, deposition, and thermal evolution as the run marches.

03

Read the result

In Results, star what matters and read ρ, φ and peak T — the metrics panel explains each.
